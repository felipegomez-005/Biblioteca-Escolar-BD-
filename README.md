# Biblioteca Escolar — Base de Datos

Proyecto semestral de Bases de Datos enfocado en mejorar la gestión de una biblioteca escolar que actualmente utiliza ABIES.

## Objetivo

Diseñar e implementar la base de datos para gestionar el catálogo, los ejemplares, los usuarios, los préstamos, las devoluciones parciales y las renovaciones.

Se propone incorporar una consulta a Google Books por ISBN para autocompletar la información bibliográfica disponible, con revisión antes de guardar.

## Estado del proyecto

Repositorio en etapa inicial. Los modelos, los scripts SQL y las pruebas se incorporarán progresivamente.
